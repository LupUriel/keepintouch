# Keep In Touch — Guide de déploiement et d'utilisation

## Où vit l'application

- Le code est hébergé sur GitHub : https://github.com/LupUriel/keepintouch
- L'application est servie par GitHub Pages à l'adresse : https://lupuriel.github.io/keepintouch/
- Toute fusion sur la branche `main` (bouton « Merge pull request » sur GitHub) redéploie
  automatiquement le site en une à deux minutes. Aucune autre manipulation n'est nécessaire.
- (L'ancien guide décrivait un déploiement Netlify par glisser-déposer : il est obsolète.)

## Mettre à jour l'application

1. Une modification arrive sous forme de « Pull Request » (PR) sur GitHub
2. Ouvrez la PR, cliquez « Merge pull request » puis « Confirm merge »
3. Attendez ~2 minutes, puis rechargez l'app : le bandeau « Nouvelle version disponible »
   apparaît — cliquez « Recharger »
4. Vérifiez le numéro de version dans ⋯ > À propos

## Installer sur Android (Samsung)

1. Ouvrez Chrome et allez sur https://lupuriel.github.io/keepintouch/
2. Attendez le chargement complet
3. Menu ⋮ (3 points) > « Ajouter à l'écran d'accueil » (ou « Installer l'application »)
4. L'icône « KIT » apparaît ; l'app s'ouvre comme une vraie application, sans barre Chrome

## Installer sur PC

1. Ouvrez Chrome et allez sur https://lupuriel.github.io/keepintouch/
2. Dans la barre d'adresse, cliquez la petite icône « Installer » (ou ⋮ > « Installer Keep In Touch »)

## Envoyer des vœux en un geste

Dans « À suivre », le bouton « Vœux » d'un anniversaire ou d'une date clé ouvre un message
prérempli que vous pouvez modifier avant de l'envoyer par mail, WhatsApp ou SMS (ou de le
copier). Les quatre modèles de vœux sont modifiables dans ⋯ > ⚙ Rencontres & agenda >
« MODÈLES DE MESSAGE ». Après l'envoi, cliquez « C'est envoyé ✓ » pour le journaliser dans
la fiche ; fermer l'aperçu ne journalise rien.

## Connexion de l'agenda Outlook (proposition automatique de dates)

L'app peut lire votre agenda Outlook (Microsoft 365) pour proposer d'elle-même des dates de
petit-déjeuner, déjeuner, dîner ou verre. Tout se passe directement entre votre navigateur et
Microsoft : aucune donnée d'agenda ne transite par un autre serveur, rien n'est stocké
(ni dans l'app, ni dans les sauvegardes), et la permission se limite à la lecture basique
du calendrier (titres, horaires, statut libre/occupé — jamais le contenu des rendez-vous).

### Se connecter / se déconnecter

- ⋯ > ⚙ Rencontres & agenda > bloc « Connecter mon agenda » > bouton « Connecter »
- Vous êtes redirigé vers la page de connexion Microsoft habituelle du cabinet, puis ramené
  dans l'app. L'état affiche alors « Agenda connecté » avec votre adresse.
- « Se déconnecter » purge le cache d'authentification local. À froid, une reconnexion
  quasi silencieuse peut être demandée : c'est normal.
- Hors ligne ou en cas de souci, l'app reste entièrement utilisable : l'écran de dates
  propose la saisie manuelle (mode secours).

### Réglages utiles

- « Collaborateurs (trigrammes) » : les initiales en tête d'un titre d'évènement
  (ex. « CME - RDV client ») signalent un créneau tenu par un collaborateur — il est donc
  considéré comme libre pour vous. Ajoutez ici tous les trigrammes de vos collaborateurs
  (ex. CME, CGI, TR). Vos propres évènements (« US - … », « USA - … ») et les évènements
  sans trigramme comptent comme occupés.
- Fenêtres par type de repas, horizon (J+3 à J+28), exclusions (semaines entièrement en
  août, 24/12 au 02/01), bascule Île-de-France/Province : tout est modifiable dans le
  même panneau.
- Note : fin juillet et en août, l'exclusion des semaines pleines d'août peut vider
  l'horizon — « Aucune date disponible » est alors normal, pas une panne.

### Enregistrement Entra (déjà fait — à refaire seulement si l'application change d'annuaire)

1. https://entra.microsoft.com > Entra ID > Inscriptions d'applications > Nouvelle inscription
   - Nom : Keep In Touch ; comptes de cet annuaire uniquement (mono-locataire)
   - Plateforme « Application à page unique » (SPA) ; URI de redirection :
     https://lupuriel.github.io/keepintouch/ (exacte) et http://localhost:8000 (développement)
2. Noter l'ID d'application (client) et l'ID de l'annuaire (locataire) — identifiants
   publics par conception, inscrits dans le code de l'app
3. API autorisées > Ajouter une autorisation > Microsoft Graph > Déléguées > Calendars.ReadBasic
4. Si l'annuaire l'exige (erreur AADSTS50105) : Applications d'entreprise > Keep In Touch >
   Propriétés > « Affectation requise ? » > Non (ou ajouter l'utilisateur dans
   « Utilisateurs et groupes »)
5. Consentement administrateur, si demandé : un administrateur ouvre
   https://login.microsoftonline.com/<ID-locataire>/adminconsent?client_id=<ID-client>
   et clique « Accepter »

## Vos données

Dans « À suivre » ou sur une fiche contact, « Déjeuner ✓ » enregistre immédiatement un déjeuner à la date du jour. Dans l'historique d'une fiche, le bouton ✏ permet de modifier une interaction existante.

## Récapitulatif hebdomadaire

À la première ouverture de chaque semaine, un récapitulatif présente les actions prioritaires
et les vœux à prévoir. Il s'affiche une fois par semaine et par appareil après sa fermeture.
La case « Récapitulatif hebdomadaire à l'ouverture » des réglages permet de le désactiver.

## Taille des entreprises

Trois gestes permettent de renseigner la taille d'une entreprise : « Rechercher l'effectif »
sur une fiche non rattachée, « Compléter les effectifs » pour les entreprises à rattacher et
« Mettre à jour les effectifs » pour actualiser les entreprises déjà rattachées par leur SIREN.
Les actions groupées montrent toujours la liste complète des dénominations ou SIREN avant
leur lancement.

Les recherches par dénomination sont affinées avec le code postal trouvé dans l'adresse, puis
les résultats sont classés localement selon leur proximité avec l'adresse de la fiche. Le bouton
« Élargir la recherche » permet de retirer ce filtre quand il est appliqué.

La source publique est SIRENE, via l'API Recherche d'entreprises de l'État. Une recherche
n'envoie que la dénomination de l'entreprise (ou son SIREN), jamais le nom du contact ni ses
coordonnées. La saisie manuelle reste possible ; elle est exclue par défaut des mises à jour
groupées et une actualisation depuis la fiche demande une confirmation avant de la remplacer.

Limite résiduelle entre appareils : lors d'une fusion, la donnée la plus récente gagne champ
par champ. Une actualisation API plus récente réalisée sur l'autre appareil peut donc
supplanter une saisie manuelle ; le rapport de fusion signale ce conflit.

- Les données sont stockées LOCALEMENT dans chaque navigateur
- Les données du PC et du mobile sont INDÉPENDANTES
- Faites régulièrement une sauvegarde (Sauvegarder/JSON dans le tableau de bord) ;
  la fusion permet de rapprocher deux appareils
- Les sauvegardes ne contiennent JAMAIS de données d'authentification Microsoft

## Protéger ses données

- Sur PC avec Chrome ou Edge, ouvrez ⋯ > Sauvegarde / Restauration, cliquez « Suivre un
  fichier de sauvegarde » et choisissez de préférence un fichier dans OneDrive. L'app le
  met ensuite à jour automatiquement après chaque enregistrement.
- Sur Android, utilisez « Partager la sauvegarde », puis importez le fichier sur l'autre
  appareil avec « Importer / fusionner ».
- « Restaurer une version » permet de repartir d'un instantané quotidien récent.
- Si une écriture locale ou celle du fichier suivi échoue, une bannière rouge vous avertit :
  exportez une sauvegarde ou re-choisissez le fichier selon le message affiché.

## Mot de passe

- À la première ouverture, l'app vous demande de créer un mot de passe
- Ce mot de passe est demandé à chaque lancement de l'app
- Le bouton 🔒 dans le tableau de bord verrouille l'app immédiatement
- Le mot de passe est stocké localement (hashé, non lisible) dans chaque navigateur
- Mot de passe perdu : effacez les données du site dans les paramètres de Chrome —
  attention, cela efface aussi vos contacts (faites une sauvegarde avant)
